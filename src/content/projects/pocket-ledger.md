## The problem
Budgeting apps feel built for accountants. Students want something that answers one question: *can I afford this?*

## The process
A Node.js API with PostgreSQL, a lightweight vanilla-JavaScript front end, and Docker so the whole app runs with one command.

## The result
My first complete full-stack project — from database schema to deployment.
